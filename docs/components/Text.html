Text Component

Componente de texto personalizable con sistema de variantes y tema

v1.0.0 React Native

📦 Instalación

Importa el componente desde el UI Kit:

import { Text } from './UI';

📖 Descripción

El componente Text es un wrapper del componente nativo de React Native que integra el sistema de tema de Kairox UI Kit. Proporciona variantes predefinidas con diferentes tamaños y pesos de fuente usando la familia tipográfica DM Sans.

💡 Tip: Este componente se conecta automáticamente al ThemeProvider y aplica las fuentes DM Sans que deben estar cargadas en tu aplicación.

⚙️ Props

Prop Tipo Requerido Valor por defecto Descripción
variant 'xs' | 'sm' | 'md' | 'lg' | 'xl' | '2xl' | '3xl' | '4xl' Opcional 'md' Define el tamaño y peso de la fuente según las variantes predefinidas
children React.ReactNode Opcional - Contenido del texto a mostrar
style StyleProp<TextStyle> Opcional - Estilos personalizados adicionales
color string Opcional '#1A1A1A' Color del texto (hereda de TextStyle)
...TextStyle TextStyle Opcional - Cualquier prop válida de TextStyle de React Native

🎨 Variantes

El componente Text utiliza variantes definidas en el sistema de tema. Las variantes disponibles se configuran en src/theme/Text.tsx:

export const variants = { xs: { fontSize: 12, fontFamily: Fonts.regular, fontWeight: '400' as const, color: '#4B5563', }, sm: { fontSize: 14, fontFamily: Fonts.regular, fontWeight: '400' as const, color: '#374151', }, md: { fontSize: 16, fontFamily: Fonts.medium, fontWeight: '400' as const, }, lg: { fontSize: 18, fontFamily: Fonts.medium, fontWeight: '500' as const, }, xl: { fontSize: 20, fontFamily: Fonts.semiBold, fontWeight: '600' as const, }, 2xl: { fontSize: 24, fontFamily: Fonts.bold, fontWeight: '700' as const, }, 3xl: { fontSize: 30, fontFamily: Fonts.bold, fontWeight: '700' as const, }, 4xl: { fontSize: 36, fontFamily: Fonts.extraBold, fontWeight: '800' as const, }, };

💻 Ejemplos de Uso

Ejemplo básico
import { Text } from './UI'; const MyComponent = () => ( <Text>Texto por defecto</Text> );
Con variantes
<Text variant="4xl">Título Principal</Text> <Text variant="2xl">Subtítulo</Text> <Text variant="md">Contenido normal</Text> <Text variant="xs">Texto pequeño</Text>
Con colores personalizados
<Text variant="lg" color="#007AFF"> Texto azul </Text> <Text variant="md" color="#E74C3C"> Texto rojo </Text>
Con estilos adicionales
<Text variant="lg" marginBottom={20} textAlign="center" textDecorationLine="underline" > Texto centrado y subrayado </Text>
Usando style prop
const styles = StyleSheet.create({ customText: { color: '#40d953', fontStyle: 'italic', letterSpacing: 1.5, }, }); <Text variant="xl" style={styles.customText}> Texto personalizado </Text>
Ejemplo completo en contexto
import React from 'react'; import { View, Text } from './UI'; const ProfileCard = () => ( <View padding={20} backgroundColor="white"> <Text variant="3xl" marginBottom={8}> Juan Pérez </Text> <Text variant="md" color="#6B7280" marginBottom={16}> Desarrollador Full Stack </Text> <Text variant="sm" color="#9CA3AF"> Miembro desde enero 2024 </Text> </View> ); export default ProfileCard;

✅ Buenas Prácticas

  • ✨ Usa las variantes predefinidas en lugar de tamaños personalizados para mantener consistencia
  • 🎨 Aprovecha los colores del tema cuando sea posible
  • 📱 Asegúrate de que las fuentes DM Sans estén cargadas antes de usar el componente
  • ♿ Considera la accesibilidad: usa tamaños de fuente legibles (no menores a 'xs')
  • 🔄 Usa 'md' como variante base para texto de cuerpo
  • 💡 Combina variantes para crear jerarquía visual clara
  • ⚡ Evita anidar demasiados componentes Text, mejor usa un solo Text con el contenido completo

🎨 Personalización del Tema

El componente Text se integra completamente con el sistema de tema. Puedes personalizar:

1. Fuentes

Modifica las fuentes en src/theme/Fonts.tsx:

const Fonts = { bold: 'DMSans-Bold', extraBold: 'DMSans-ExtraBold', light: 'DMSans-Light', regular: 'DMSans-Regular', medium: 'DMSans-Medium', semiBold: 'DMSans-SemiBold', };

2. Colores del Tema

Usa los colores del tema en lugar de valores hardcodeados:

// En lugar de: <Text color="#007AFF">Texto</Text> // Usa: <Text color="primary.500">Texto</Text> <Text color="accent.600">Texto</Text>

3. Tema Personalizado

Puedes pasar un tema personalizado al ThemeProvider:

const customTheme = { components: { Text: { baseStyle: { fontFamily: 'CustomFont', color: '#333333', }, variants: { // Tus variantes personalizadas }, defaultProps: { variant: 'lg', }, }, }, }; <ThemeProvider customTheme={customTheme}> <App /> </ThemeProvider>

🔧 Notas Técnicas

Dependencias

  • react-native: Componente base Text
  • ThemeProvider: Proveedor de tema necesario
  • expo-font: Para cargar fuentes DM Sans

Sistema de Tema

El componente se conecta automáticamente al ThemeProvider y obtiene la configuración de texto desde theme.components.Text. Si no encuentra el tema, usa estilos por defecto.

Orden de Prioridad de Estilos

  1. Base style del tema
  2. Variant style seleccionado
  3. Props de TextStyle pasadas directamente
  4. Style prop (mayor prioridad)

Integración con el Tema

El componente Text se integra automáticamente con:

  • 🎨 Colores del tema: Usa theme.colors para colores consistentes
  • 🔤 Fuentes del tema: Aplica las fuentes DM Sans configuradas
  • 📏 Espaciado: Respeta el sistema de espaciado del tema
  • 🎯 Variantes: Utiliza las variantes predefinidas del tema
