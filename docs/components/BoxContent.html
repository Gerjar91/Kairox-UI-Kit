BoxContent Component

Contenedor con scroll y manejo inteligente del teclado usando KeyboardAwareScrollView

v1.0.0 React Native Keyboard Aware

📦 Instalación

import { BoxContent } from './UI';

📖 Descripción

BoxContent es un contenedor scrollable que maneja automáticamente el teclado en dispositivos móviles. Usa KeyboardAwareScrollView de react-native-keyboard-controller para asegurar que los inputs no queden ocultos detrás del teclado.

💡 Uso recomendado: Usa BoxContent dentro de BoxContainer para pantallas con formularios o contenido scrollable que necesite interactuar con el teclado.

⚙️ Props

  • children (React.ReactNode): Contenido scrollable
  • keyboardShouldPersistTaps (boolean | 'always' | 'never' | 'handled'): Comportamiento del teclado. Por defecto: 'handled'
  • backgroundColor (string): Color de fondo. Por defecto: 'white'
  • bottomOffset (number): Offset inferior para el teclado. Por defecto: 100
  • style (ViewStyle): Estilos personalizados

💻 Ejemplos

Formulario básico
import { BoxContainer, BoxContent } from './UI'; const LoginForm = () => ( <BoxContainer> <BoxContent> <TextInput placeholder="Email" /> <TextInput placeholder="Password" /> <Button title="Iniciar sesión" /> </BoxContent> </BoxContainer> );
Formulario largo con múltiples campos
<BoxContainer backgroundColor="#F8F9FA"> <BoxContent bottomOffset={150}> <Text variant="2xl">Registro</Text> <TextInput placeholder="Nombre completo" /> <TextInput placeholder="Email" /> <TextInput placeholder="Teléfono" /> <TextInput placeholder="Dirección" /> <TextInput placeholder="Ciudad" /> <Button title="Registrarse" /> </BoxContent> </BoxContainer>
Lista scrollable
<BoxContainer> <BoxContent keyboardShouldPersistTaps="always"> {data.map(item => ( <Card key={item.id}> {item.content} </Card> ))} </BoxContent> </BoxContainer>

🔑 Características Clave

  • ⌨️ Manejo automático del teclado: Los inputs nunca quedan ocultos
  • 📜 Scroll automático: Se desplaza al input activo
  • 🎯 Personalizable: Control sobre el comportamiento del teclado
  • ⚡ Optimizado: Usa KeyboardAwareScrollView de forma eficiente

✅ Buenas Prácticas

  • 📱 Usa BoxContent para cualquier pantalla con inputs
  • 🎯 Ajusta bottomOffset según la altura de tu footer o botones
  • ⌨️ Usa keyboardShouldPersistTaps="handled" para la mayoría de casos
  • 🔄 Combina siempre con BoxContainer para estructura consistente

🔧 Notas Técnicas

Dependencias:

  • react-native-keyboard-controller: Para KeyboardAwareScrollView

Estructura interna:

El componente envuelve el contenido en dos Views con flex:1 y luego usa KeyboardAwareScrollView para el manejo del scroll y teclado.
