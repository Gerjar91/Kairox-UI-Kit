# 📚 Documentación Kairox UI Kit

Bienvenido a la documentación oficial de Kairox UI Kit.

## 🚀 Cómo Usar la Documentación

1. Abre el archivo `index.html` en tu navegador web
2. Navega a través de los diferentes componentes
3. Cada componente tiene su propia página de documentación detallada

## 📂 Estructura

```
docs/
├── index.html                 # Página principal de documentación
├── components/
│   └── Text.html             # Documentación del componente Text
│   └── [Más componentes próximamente]
└── README.md                 # Este archivo
```

## 🎯 ¿Qué encontrarás en cada documentación?

Cada componente incluye:

- **Instalación**: Cómo importar el componente
- **Descripción**: Para qué sirve y cuándo usarlo
- **Props**: Tabla completa de todas las propiedades disponibles
- **Variantes**: Diferentes estilos predefinidos (cuando aplique)
- **Ejemplos de Uso**: Código de ejemplo listo para copiar y pegar
- **Buenas Prácticas**: Recomendaciones para usar el componente
- **Notas Técnicas**: Detalles de implementación

## 💡 Consejos

1. **Lee la documentación completa** de cada componente antes de usarlo
2. **Revisa los ejemplos de código** para ver casos de uso reales
3. **Sigue las buenas prácticas** recomendadas para cada componente
4. **Mantén la consistencia** usando las variantes predefinidas

## 🛠️ Desarrollo

Si quieres agregar documentación para un nuevo componente:

1. Crea un nuevo archivo HTML en `docs/components/`
2. Usa la misma estructura que `Text.html` como plantilla
3. Actualiza el `index.html` para incluir el enlace
4. Documenta todas las props, variantes y ejemplos

## 📝 Formato

La documentación está en HTML estático por las siguientes razones:

- ✓ Funciona sin necesidad de servidor
- ✓ Se puede abrir directamente desde el sistema de archivos
- ✓ Fácil de compartir (envía los archivos HTML)
- ✓ Estilos incluidos en el mismo archivo
- ✓ No requiere build o compilación

## 🎨 Personalización

Puedes personalizar los estilos de la documentación editando la sección `<style>` en cada archivo HTML.
