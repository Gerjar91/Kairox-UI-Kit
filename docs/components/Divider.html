Divider Component

Separadores visuales horizontales y verticales personalizables

v1.0.0 React Native

📦 Instalación

Importa el componente desde el UI Kit:

import { Divider } from './UI';

📖 Descripción

El componente Divider es un separador visual simple pero versátil que ayuda a organizar y delimitar contenido. Soporta orientación horizontal y vertical, con grosor, color y longitud completamente personalizables.

💡 Tip: Los dividers son excelentes para mejorar la jerarquía visual y la legibilidad al separar secciones de contenido sin agregar peso visual excesivo.

⚙️ Props

Prop Tipo Requerido Valor por defecto Descripción
orientation 'horizontal' | 'vertical' Opcional 'horizontal' Orientación del divider
thickness number Opcional 1 Grosor del divider en píxeles
color string Opcional '#E0E0E0' Color del divider
length DimensionValue Opcional '100%' Longitud del divider (ancho para horizontal, alto para vertical)
style ViewStyle Opcional - Estilos personalizados adicionales
...ViewStyle ViewStyle Opcional - Props de estilo como margin, padding, etc.

💼 Casos de Uso Comunes

  • 📋 Listas: Separar items en listas y menús
  • 📄 Secciones: Delimitar diferentes secciones de contenido
  • 🎨 Tarjetas: Separar elementos dentro de tarjetas
  • 🔧 Toolbars: Separar grupos de botones o iconos
  • 📊 Dashboards: Delimitar widgets y estadísticas
  • 📝 Formularios: Separar grupos de campos
  • 🏷️ Headers: Línea decorativa bajo títulos
  • ⚙️ Configuración: Separar grupos de opciones

✅ Buenas Prácticas

  • 🎨 Usa colores sutiles que no compitan con el contenido (#E0E0E0 o #F3F4F6)
  • 📏 Mantén el grosor delgado (1-2px) para la mayoría de casos
  • 📍 Agrega márgenes apropiados para dar espacio al contenido
  • 🔄 Usa dividers consistentemente en toda la aplicación
  • ⚡ No abuses de los dividers - úsalos solo cuando mejoren la legibilidad
  • ♿ Asegura suficiente contraste con el fondo
  • 📱 En listas largas, considera usar dividers más sutiles
  • 🎯 Usa dividers verticales con moderación

🔧 Notas Técnicas

Dependencias

  • react-native: View

Implementación

El componente calcula dinámicamente sus dimensiones según la orientación:

const dividerStyle = orientation === 'horizontal' ? { width: length, height: thickness, backgroundColor: color } : { width: thickness, height: length, backgroundColor: color };

Flexibilidad

El componente acepta tanto props específicas como cualquier prop de ViewStyle, permitiendo máxima flexibilidad en el posicionamiento y estilo.

♿ Accesibilidad

Los dividers son elementos puramente visuales y no requieren consideraciones especiales de accesibilidad. Sin embargo:

  • Asegura que haya suficiente contraste con el fondo (mínimo 3:1)
  • No dependas únicamente de dividers para separar contenido - usa también espaciado
  • Los screen readers ignorarán los dividers, así que la estructura del contenido debe ser clara sin ellos
