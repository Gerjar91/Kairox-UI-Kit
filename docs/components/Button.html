Button Component

Componente de botón interactivo con múltiples variantes y sistema de tema

v1.0.0 React Native

📦 Instalación

Importa el componente desde el UI Kit:

import { Button } from './UI';

📖 Descripción

El componente Button es un wrapper de TouchableOpacity que proporciona una interfaz consistente para botones interactivos. Se integra completamente con el sistema de tema de Kairox UI Kit y ofrece tres variantes principales: solid, outline y link.

💡 Tip: El componente Button se conecta automáticamente al ThemeProvider y aplica las fuentes ComicNeue configuradas. Soporta iconos, estados deshabilitados y personalización completa.

⚙️ Props

Prop Tipo Requerido Valor por defecto Descripción
onPress (event: GestureResponderEvent) => void Requerido - Función que se ejecuta al presionar el botón
title string Opcional - Texto del botón (alternativa a children)
variant 'solid' | 'outline' | 'link' Opcional 'solid' Variante visual del botón
disabled boolean Opcional false Deshabilita el botón y reduce su opacidad
children React.ReactNode Opcional - Contenido personalizado del botón (tiene prioridad sobre title)
style ViewStyle Opcional - Estilos personalizados para el contenedor del botón
textStyle TextStyle Opcional - Estilos personalizados para el texto del botón
activeOpacity number Opcional 0.8 Opacidad al presionar el botón (0-1)
leftIcon React.ReactElement Opcional - Icono a mostrar a la izquierda del texto
...TouchableOpacityProps TouchableOpacityProps Opcional - Cualquier prop válida de TouchableOpacity
...ViewStyle ViewStyle Opcional - Props de estilo como marginTop, padding, etc.

✅ Buenas Prácticas

  • ✨ Usa la variante 'solid' para acciones principales y llamativas
  • 🎨 Usa la variante 'outline' para acciones secundarias
  • 🔗 Usa la variante 'link' para navegación o acciones terciarias
  • ♿ Siempre proporciona feedback visual al usuario (estados disabled, loading)
  • 📱 Asegúrate de que los botones tengan un área táctil mínima de 44x44 puntos
  • 💡 Usa títulos descriptivos que indiquen claramente la acción
  • ⚡ Maneja estados de carga para operaciones asíncronas
  • 🎯 Evita múltiples botones primarios en la misma pantalla
  • 🔒 Deshabilita botones cuando la acción no esté disponible

🎭 Estados del Botón

Estado Normal

El estado predeterminado del botón, listo para interacción.

Estado Presionado (Active)

Controlado por la prop activeOpacity. Por defecto es 0.8.

<Button title="Presionar" activeOpacity={0.6} // Más transparente al presionar onPress={handlePress} />

Estado Deshabilitado

Reduce la opacidad a 0.7 y previene la interacción.

<Button title="No disponible" disabled={true} onPress={handlePress} />
⚠️ Importante: Cuando un botón está deshabilitado, el evento onPress no se ejecutará, pero es obligatorio proporcionarlo.

🎨 Personalización del Tema

El componente Button se integra completamente con el sistema de tema.

1. Personalizar Colores

Modifica los colores en src/theme/Button.tsx:

export const variants = { solid: { button: { backgroundColor: '#40d953', // Tu color primario }, text: { color: 'white', }, }, };

2. Personalizar Estilos Base

const baseStyle: ViewStyle = { borderRadius: 20, // Bordes más redondeados paddingVertical: 16, // Botones más grandes paddingHorizontal: 32, };

3. Agregar Nuevas Variantes

export const variants = { solid: { /* ... */ }, outline: { /* ... */ }, link: { /* ... */ }, // Nueva variante personalizada gradient: { button: { backgroundColor: '#33729E', shadowColor: '#33729E', shadowOffset: { width: 0, height: 4 }, shadowOpacity: 0.3, shadowRadius: 8, elevation: 8, }, text: { color: 'white', fontFamily: Fonts.bold, }, }, };

4. Tema Personalizado Global

const customTheme = { components: { Button: { baseStyle: { borderRadius: 15, }, variants: { // Tus variantes personalizadas }, defaultProps: { variant: 'solid', }, }, }, }; <ThemeProvider customTheme={customTheme}> <App /> </ThemeProvider>

🔧 Notas Técnicas

Dependencias

  • react-native: TouchableOpacity como componente base
  • ThemeProvider: Sistema de tema requerido
  • Text: Componente de texto del UI Kit
  • expo-font: Para cargar fuentes ComicNeue

Orden de Prioridad de Estilos

  1. Base style del tema (menor prioridad)
  2. Variant style seleccionado
  3. Disabled style (si está deshabilitado)
  4. Props de ViewStyle pasadas directamente (rest props)
  5. Style prop (mayor prioridad)

Renderizado de Contenido

El componente determina qué renderizar en este orden:

  1. Si existe children, lo renderiza directamente
  2. Si no hay children, renderiza el title envuelto en un componente Text

Optimización

El componente usa useMemo para calcular los estilos del botón y del texto, evitando recalcular en cada renderizado. Solo se recalcula cuando cambian las dependencias: variant, disabled, theme, o rest props.

💡 Performance Tip: Si pasas muchas props de estilo directamente, considera usar la prop style con un objeto memoizado o creado con StyleSheet.create() para mejor rendimiento.

♿ Accesibilidad

Mejora la accesibilidad de tus botones con estas props adicionales:

<Button title="Eliminar" onPress={handleDelete} accessible={true} accessibilityLabel="Eliminar elemento" accessibilityHint="Doble toque para eliminar el elemento seleccionado" accessibilityRole="button" />

Recomendaciones

  • Usa accessibilityLabel para describir la acción del botón
  • Proporciona accessibilityHint para contexto adicional
  • Asegura que el área táctil sea de al menos 44x44 puntos
  • Usa suficiente contraste entre el texto y el fondo del botón
  • Proporciona feedback visual claro en todos los estados
