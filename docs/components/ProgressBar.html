ProgressBar Component

Barras de progreso animadas con valores de 0 a 100 y personalización completa

v1.0.0 React Native Animated

📦 Instalación

Importa el componente desde el UI Kit:

import { ProgressBar } from './UI';

📖 Descripción

El componente ProgressBar muestra el progreso de una tarea u operación mediante una barra visual animada. Acepta valores de 0 a 100 y puede ser completamente personalizado en términos de color, altura, animación y más.

💡 Tip: Las barras de progreso son ideales para mostrar el avance de descargas, uploads, instalaciones, completitud de perfiles, y cualquier tarea con progreso cuantificable.

⚙️ Props

Prop Tipo Requerido Valor por defecto Descripción
progress number Requerido 0 Valor del progreso (0-100)
height number Opcional 8 Altura de la barra en píxeles
backgroundColor string Opcional '#E5E7EB' Color de fondo de la barra
progressColor string Opcional '#3B82F6' Color de la barra de progreso
borderRadius number Opcional 4 Radio de los bordes redondeados
animated boolean Opcional true Si la barra debe animarse
animationDuration number Opcional 300 Duración de la animación en ms
marginBottom number Opcional 0 Margen inferior
style ViewStyle Opcional - Estilos personalizados

💼 Casos de Uso Comunes

  • 📥 Descargas: Mostrar progreso de descargas de archivos
  • 📤 Uploads: Indicar avance de subida de archivos
  • 👤 Perfiles: Completitud de información de perfil
  • 📝 Formularios: Progreso en formularios multi-paso
  • 🎯 Objetivos: Avance hacia metas u objetivos
  • 💪 Skills: Nivel de habilidades o competencias
  • 📊 Estadísticas: Visualización de datos porcentuales
  • ⏳ Instalaciones: Progreso de instalación de apps

✅ Buenas Prácticas

  • 📊 Acompaña la barra con texto que indique el porcentaje o contexto
  • 🎨 Usa colores apropiados (verde para completado, azul para en progreso)
  • ⏱️ Mantén la animación suave (300-500ms es ideal)
  • 📏 Usa altura de 6-12px para la mayoría de casos
  • ✅ Cambia a verde cuando el progreso llega al 100%
  • 🔄 Actualiza el progreso de forma frecuente pero no excesiva
  • 💬 Proporciona feedback adicional cuando el proceso complete
  • 📱 Asegura que la barra sea visible en todas las pantallas

✨ Animación

El componente usa Animated.timing para animar el ancho de la barra de progreso, creando una transición suave cuando el valor cambia.

Animated.timing(animatedWidth, { toValue: clampedProgress, duration: animationDuration, useNativeDriver: false, // No se puede usar para width }).start(); // Interpolación del ancho const widthInterpolation = animatedWidth.interpolate({ inputRange: [0, 100], outputRange: ['0%', '100%'], });

Características

  • 🎯 Clamping automático: Los valores se limitan entre 0-100
  • 🔄 Interpolación: Conversión fluida de número a porcentaje
  • ⚡ Desactivable: Puedes deshabilitar la animación con animated={false}
  • ⏱️ Duración personalizable: Ajusta la velocidad de la animación

🔧 Notas Técnicas

Dependencias

  • react-native: View, Animated

Validación de Valores

El componente automáticamente limita el progreso entre 0 y 100:

const clampedProgress = Math.min(Math.max(progress, 0), 100);

Native Driver

La animación no puede usar useNativeDriver: true porque las propiedades de layout (width, height) no son soportadas en el hilo nativo. El componente usa useNativeDriver: false para animar el ancho correctamente.
