CustomStatusBar Component

Barra de estado personalizable con SafeAreaView integrado

v1.0.0 React Native

📦 Instalación

import { CustomStatusBar } from './UI';

📖 Descripción

CustomStatusBar es un wrapper del StatusBar nativo que incluye SafeAreaView automáticamente. Simplifica la configuración de la barra de estado en tu aplicación.

💡 Tip: Coloca este componente al inicio de tu App o en cada pantalla que necesite un estilo de status bar diferente.

⚙️ Props

Acepta todas las props de StatusBar de React Native, incluyendo:

  • backgroundColor (string): Color de fondo de la status bar (Android)
  • barStyle ('default' | 'light-content' | 'dark-content'): Estilo del contenido
  • hidden (boolean): Si debe estar oculta
  • translucent (boolean): Si es translúcida (Android)

💻 Ejemplos

Status bar claro
import { CustomStatusBar } from './UI'; <CustomStatusBar backgroundColor="white" barStyle="dark-content" />
Status bar oscuro
<CustomStatusBar backgroundColor="#1F2937" barStyle="light-content" />
En App.tsx
import { CustomStatusBar } from './UI'; export default function App() { return ( <> <CustomStatusBar backgroundColor="#33729E" barStyle="light-content" /> <AppNavigator /> </> ); }
Translúcida (Android)
<CustomStatusBar backgroundColor="transparent" barStyle="light-content" translucent />

🎨 Estilos Comunes

// Tema claro <CustomStatusBar backgroundColor="white" barStyle="dark-content" /> // Tema oscuro <CustomStatusBar backgroundColor="#000000" barStyle="light-content" /> // Color de marca <CustomStatusBar backgroundColor="#33729E" barStyle="light-content" />

📝 Notas

  • iOS: backgroundColor no tiene efecto, solo barStyle
  • Android: backgroundColor cambia el color de la status bar
  • SafeAreaView: Se incluye automáticamente para respetar el notch
