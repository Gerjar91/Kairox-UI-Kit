Accordion Component

Contenido expandible y colapsable con animaciones suaves

v1.0.0 React Native Animated

📦 Instalación

Importa el componente desde el UI Kit:

import { Accordion } from './UI';

📖 Descripción

El componente Accordion permite mostrar y ocultar contenido de forma expandible. Incluye animaciones suaves para el despliegue/colapso del contenido y rotación del icono indicador. Perfecto para FAQs, menús complejos y organización de información.

💡 Tip: Los accordions son ideales para ahorrar espacio en pantalla mientras mantienes la información accesible. Son especialmente útiles en móviles donde el espacio es limitado.

⚙️ Props

Prop Tipo Requerido Valor por defecto Descripción
title string Requerido - Título del accordion
children React.ReactNode Requerido - Contenido que se muestra/oculta
defaultExpanded boolean Opcional false Si debe estar expandido inicialmente
onToggle (isExpanded: boolean) => void Opcional - Callback cuando se expande/colapsa
style ViewStyle Opcional - Estilos del contenedor principal
headerStyle ViewStyle Opcional - Estilos del header/título
titleStyle TextStyle Opcional - Estilos del texto del título
contentStyle ViewStyle Opcional - Estilos del contenido expandible
iconColor string Opcional 'black' Color del icono de chevron
iconSize number Opcional 20 Tamaño del icono
leftIcon React.ReactElement Opcional - Icono a la izquierda del título
...ViewStyle ViewStyle Opcional - Props de estilo adicionales

✅ Buenas Prácticas

  • 📝 Usa títulos descriptivos y concisos
  • 🎯 Agrupa contenido relacionado en el mismo accordion
  • ⚡ No anides accordions muy profundamente (máximo 2 niveles)
  • 📱 Considera el espacio en móviles - los accordions son ideales aquí
  • 🔄 Usa defaultExpanded para contenido importante
  • 💬 Proporciona feedback visual claro del estado expandido/colapsado
  • ♿ Asegura que el área de click del header sea suficientemente grande
  • 📊 No uses accordions para contenido que debe estar siempre visible

✨ Animación

El componente usa dos animaciones paralelas: una para la altura del contenido y otra para la rotación del icono chevron.

Animated.parallel([ // Animación de altura Animated.timing(animatedHeight, { toValue: newExpandedState ? 1 : 0, duration: 500, useNativeDriver: false, }), // Animación de rotación del icono Animated.timing(rotateValue, { toValue: newExpandedState ? 1 : 0, duration: 400, useNativeDriver: true, }), ]).start();

Interpolaciones

// Rotación del icono (0° a 180°) const rotateInterpolate = rotateValue.interpolate({ inputRange: [0, 1], outputRange: ['0deg', '180deg'], }); // Altura máxima del contenido const maxHeight = animatedHeight.interpolate({ inputRange: [0, 1], outputRange: [0, 1000], // Altura máxima de 1000px });

🔧 Notas Técnicas

Dependencias

  • react-native: View, Text, TouchableOpacity, Animated
  • @expo/vector-icons: Ionicons para el chevron
  • Icon: Componente de icono del UI Kit

Estado Interno

El componente maneja su propio estado de expandido/colapsado:

const [expanded, setExpanded] = useState(defaultExpanded);

Limitación de Altura

La altura máxima del contenido está limitada a 1000px. Si necesitas más espacio, puedes modificar el outputRange en la interpolación de maxHeight.
