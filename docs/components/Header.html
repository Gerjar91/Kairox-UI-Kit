Header Component

Cabecera de navegación con título, botón back y acciones personalizables

v1.0.0 React Native

📦 Instalación

import { Header } from './UI';

📖 Descripción

El componente Header proporciona una barra de navegación consistente con soporte para título, botón de retroceso (back button con chevron-left), icono derecho personalizable y altura ajustable.

💡 Tip: El Header incluye RemovableView que oculta automáticamente los iconos cuando no hay callback definido, manteniendo el layout limpio.

⚙️ Props

Prop Tipo Requerido Valor por defecto Descripción
title string Opcional - Título del header
onLeftPress () => void Opcional - Callback del botón izquierdo (back)
rightIcon React.ReactNode Opcional - Icono o elemento derecho
onRightPress () => void Opcional - Callback del botón derecho
children React.ReactNode Opcional - Contenido personalizado (reemplaza title)
backgroundColor string Opcional 'transparent' Color de fondo
height number Opcional 60 Altura del header
colorIcon string Opcional 'black' Color de los iconos
sizeIcon number Opcional 40 Tamaño del icono back
titleStyle TextStyle Opcional - Estilos del título
style ViewStyle Opcional - Estilos del contenedor
...ViewStyle ViewStyle Opcional - Props de estilo adicionales

💼 Casos de Uso Comunes

  • 🧭 Navegación: Pantallas con botón back
  • 📱 Pantallas de detalle: Productos, perfiles, artículos
  • ⚙️ Configuración: Headers con menú de opciones
  • ✏️ Edición: Headers con botón guardar o cancelar
  • 🔍 Búsqueda: Headers con barra de búsqueda personalizada
  • 📊 Dashboards: Headers con filtros o acciones

✅ Buenas Prácticas

  • 🎯 Usa siempre el botón back en pantallas secundarias
  • 📏 Mantén la altura consistente en toda la app (60px es estándar)
  • 🎨 Usa colores que contrasten bien con el contenido
  • ♿ Asegura que los iconos sean fácilmente táctiles (40px mínimo)
  • 📱 Limita las acciones del header a 1-2 botones
  • 💬 Usa títulos descriptivos pero concisos

🔧 Notas Técnicas

Estructura

El header está dividido en tres secciones:

  • leftContainer: Contiene el botón back (chevron-left)
  • centerContainer: Contiene el título o children personalizado
  • rightContainer: Contiene el icono/acción derecha

RemovableView

El componente usa RemovableView internamente para ocultar automáticamente los contenedores left y right cuando no hay callback definido, evitando espacios vacíos.

Dependencias

  • @expo/vector-icons: Para el icono MaterialCommunityIcons chevron-left
  • Icon: Componente de icono del UI Kit
  • RemovableView: Componente interno del UI Kit
