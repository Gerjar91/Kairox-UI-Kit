Checkbox Component

Casillas de verificación personalizables con iconos, etiquetas y múltiples tamaños

v1.0.0 React Native

📦 Instalación

Importa el componente desde el UI Kit:

import { Checkbox } from './UI';

📖 Descripción

El componente Checkbox permite a los usuarios seleccionar una o más opciones de un conjunto. Ofrece 3 tamaños, soporte para iconos personalizados, etiquetas configurables y estados deshabilitados.

💡 Tip: Puedes usar iconos personalizados para el checkmark usando la prop icon, lo que permite crear checkboxes únicos que se alineen con el diseño de tu aplicación.

⚙️ Props

Prop Tipo Requerido Valor por defecto Descripción
checked boolean Requerido - Estado del checkbox (true = marcado, false = desmarcado)
onChange (checked: boolean) => void Requerido - Función que se ejecuta cuando cambia el estado
size 'sm' | 'md' | 'lg' Opcional 'md' Tamaño del checkbox
disabled boolean Opcional false Deshabilita el checkbox
label string Opcional - Texto de la etiqueta
labelPosition 'left' | 'right' Opcional 'right' Posición de la etiqueta
activeColor string Opcional '#007AFF' Color de fondo cuando está marcado
inactiveColor string Opcional '#D1D5DB' Color de fondo cuando está desmarcado
activeborderColor string Opcional '#007AFF' Color del borde cuando está marcado
inactiveborderColor string Opcional '#D1D5DB' Color del borde cuando está desmarcado
rounded boolean Opcional false Bordes redondeados
icon React.ReactElement Opcional - Icono personalizado para el checkmark
iconColor string Opcional 'white' Color del icono
style ViewStyle Opcional - Estilos personalizados

💼 Casos de Uso Comunes

  • 📝 Formularios: Aceptar términos, condiciones, políticas
  • ⚙️ Configuración: Activar/desactivar múltiples opciones
  • 🎯 Filtros: Selección múltiple en búsquedas y filtros
  • 📋 Listas de tareas: Marcar tareas completadas
  • ✅ Selección múltiple: Elegir varios items de una lista
  • 🔐 Permisos: Solicitar permisos de la app
  • 📧 Preferencias: Suscripciones a newsletters o notificaciones

✅ Buenas Prácticas

  • 🏷️ Siempre incluye una etiqueta descriptiva con el checkbox
  • 📍 Coloca la etiqueta a la derecha del checkbox (convención estándar)
  • ♿ Asegura un área táctil mínima de 44x44 puntos
  • 📏 Usa tamaño 'md' para la mayoría de casos, 'sm' para opciones secundarias
  • 🎨 Usa colores verdes para indicar "completado" o "éxito"
  • 🔄 Los cambios deben reflejarse inmediatamente
  • 📱 Agrupa checkboxes relacionados visualmente
  • 💬 Usa texto claro y conciso en las etiquetas
  • ⚠️ Valida los checkboxes requeridos antes de enviar formularios

🔧 Notas Técnicas

Dependencias

  • react-native: TouchableOpacity, View, Text
  • Icon: Componente de icono del UI Kit (para iconos personalizados)

Estados

El componente Checkbox es controlado, lo que significa que debes gestionar su estado externamente:

// Estado manejado por el componente padre const [checked, setChecked] = useState(false); <Checkbox checked={checked} onChange={setChecked} />

Icono Personalizado

Cuando usas la prop icon, el componente renderiza ese icono cuando está marcado:

{icon && checked && ( <Icon color={iconColor} size={sizeValues.checkmarkSize} as={icon} /> )}

♿ Accesibilidad

Mejora la accesibilidad de tus checkboxes:

<Checkbox checked={isChecked} onChange={setIsChecked} label="Acepto los términos" accessible={true} accessibilityRole="checkbox" accessibilityState={{ checked: isChecked }} accessibilityLabel="Aceptar términos y condiciones" />

Recomendaciones

  • Usa etiquetas descriptivas que expliquen claramente la opción
  • Asegura suficiente contraste entre el checkbox y el fondo
  • El área táctil debe ser fácil de presionar (mínimo 44x44)
  • Agrupa checkboxes relacionados con un título o descripción
