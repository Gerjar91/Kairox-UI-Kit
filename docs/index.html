Kairox UI Kit

Librería de componentes UI para React Native con tema personalizable

v1.0.0

Documentación

Kairox UI Kit es una colección completa de componentes UI para React Native, diseñada para acelerar el desarrollo de aplicaciones móviles con un sistema de tema coherente y personalizable.

Comenzar

1. Instalación

Instala las dependencias necesarias:

npm install @expo/vector-icons expo-font react-native-keyboard-controller

2. Configuración

Configura el tema y las fuentes en tu aplicación.

Ver Guía de Configuración →

3. Uso Básico

Importa y usa los componentes:

import { Text, Button } from 'kairox-ui-kit';
