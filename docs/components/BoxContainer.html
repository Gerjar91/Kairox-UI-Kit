BoxContainer Component

Contenedor flex con backgroundColor personalizable - Patrón de diseño recomendado

v1.0.0 React Native

📦 Instalación

import { BoxContainer } from './UI';

📖 Descripción

BoxContainer es un contenedor simple con flex: 1 y un color de fondo personalizable. Según las preferencias del usuario, este componente se usa junto con BoxContent para estructurar pantallas.

💡 Patrón: BoxContainer se usa como contenedor principal de la pantalla, mientras que BoxContent maneja el contenido scrollable con teclado.

⚙️ Props

  • backgroundColor (string, opcional): Color de fondo. Por defecto: 'white'
  • children (React.ReactNode): Contenido del contenedor

💻 Ejemplos

Uso básico
import { BoxContainer } from './UI'; const Screen = () => ( <BoxContainer> <Text>Contenido de la pantalla</Text> </BoxContainer> );
Con color de fondo personalizado
<BoxContainer backgroundColor="#F8F9FA"> <Text>Fondo gris claro</Text> </BoxContainer>
Patrón recomendado con BoxContent
import { BoxContainer, BoxContent } from './UI'; const FormScreen = () => ( <BoxContainer backgroundColor="white"> <BoxContent> <{/* Contenido scrollable */}> <Text>Formulario...</Text> </BoxContent> </BoxContainer> );

✅ Cuándo usar

  • ✨ Como contenedor principal de pantallas
  • 🎨 Cuando necesitas un fondo de color específico
  • 📱 En combinación con BoxContent para pantallas con formularios
  • 🔧 Para mantener consistencia en la estructura de pantallas
