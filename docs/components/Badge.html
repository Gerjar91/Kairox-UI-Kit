Badge Component

Etiquetas de estado con múltiples variantes, tamaños y estilos personalizables

v1.0.0 React Native

📦 Instalación

Importa el componente desde el UI Kit:

import { Badge } from './UI';

📖 Descripción

El componente Badge es perfecto para mostrar etiquetas, estados, categorías o información destacada. Ofrece 7 variantes de color, 3 tamaños y múltiples opciones de personalización como bordes redondeados y estilo outlined.

💡 Tip: Los badges son ideales para mostrar estados (activo/inactivo), categorías, contadores de notificaciones o cualquier información que necesite destacarse visualmente.

⚙️ Props

Prop Tipo Requerido Valor por defecto Descripción
children React.ReactNode Opcional - Contenido del badge (texto o elementos)
variant 'primary' | 'secondary' | 'success' | 'warning' | 'error' | 'info' | 'neutral' Opcional 'primary' Variante de color del badge
size 'sm' | 'md' | 'lg' Opcional 'md' Tamaño del badge
rounded boolean Opcional false Si es true, el badge tiene bordes completamente redondeados
outlined boolean Opcional false Si es true, el badge tiene solo borde sin fondo
showDot boolean Opcional false Muestra un punto indicador
dotPosition 'left' | 'right' Opcional 'left' Posición del punto indicador
onClose () => void Opcional - Función para cerrar/remover el badge
style ViewStyle Opcional - Estilos personalizados para el contenedor
textStyle TextStyle Opcional - Estilos personalizados para el texto
backgroundColor string Opcional - Color de fondo personalizado
textColor string Opcional - Color de texto personalizado
borderColor string Opcional - Color de borde personalizado (cuando outlined=true)

💼 Casos de Uso Comunes

  • 🔔 Notificaciones: Mostrar contadores de mensajes no leídos
  • 📊 Estados: Indicar el estado de órdenes, tareas o procesos
  • 🏷️ Categorías: Etiquetar contenido con categorías o tags
  • ✅ Disponibilidad: Mostrar si algo está activo, disponible o en stock
  • ⭐ Destacados: Marcar elementos como "Nuevo", "Popular", "Oferta"
  • 📈 Niveles: Mostrar niveles de prioridad (Alta, Media, Baja)
  • 🎖️ Logros: Mostrar badges de logros o insignias

✅ Buenas Prácticas

  • 🎨 Usa colores consistentes para estados similares en toda tu app
  • 📏 Mantén el texto corto y conciso (1-2 palabras idealmente)
  • 🔤 Usa tamaño 'sm' para badges secundarios o contadores
  • 🎯 Usa 'outlined' cuando quieras un estilo más sutil
  • 🌈 Reserva colores específicos para significados consistentes (error=rojo, success=verde)
  • ♿ Asegúrate de que haya suficiente contraste entre texto y fondo
  • 📱 Evita usar demasiados badges juntos para no abrumar visualmente
  • 💡 Combina 'rounded' con badges pequeños para un look más moderno

🎨 Configuración de Colores

🔧 Notas Técnicas

Dependencias

  • react-native: View y Text como componentes base

Personalización

Puedes personalizar completamente los colores usando las props backgroundColor, textColor y borderColor, que tienen prioridad sobre las variantes predefinidas.

Orden de Prioridad de Estilos

  1. Estilos base del badge
  2. Estilos de la variante seleccionada
  3. Estilos del tamaño seleccionado
  4. Props de color personalizadas (backgroundColor, textColor, borderColor)
  5. Style prop (mayor prioridad)
