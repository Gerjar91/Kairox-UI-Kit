Switch Component

Interruptor de toggle animado con múltiples tamaños y colores personalizables

v1.0.0 React Native Animated

📦 Instalación

Importa el componente desde el UI Kit:

import { Switch } from './UI';

📖 Descripción

El componente Switch es un interruptor de toggle personalizable que permite a los usuarios activar o desactivar una opción. Incluye animaciones suaves con spring physics, 4 tamaños predefinidos y colores totalmente personalizables.

💡 Tip: El componente usa Animated de React Native para crear transiciones fluidas y naturales. Las animaciones usan spring physics para un movimiento más orgánico.

⚙️ Props

Prop Tipo Requerido Valor por defecto Descripción
value boolean Requerido - Estado actual del switch (true = activo, false = inactivo)
onValueChange (value: boolean) => void Requerido - Función que se ejecuta cuando cambia el estado
size 'sm' | 'md' | 'lg' | 'xl' Opcional 'md' Tamaño del switch
thumbColor string Opcional 'white' Color del botón deslizante (thumb)
backgroundActiveColor string Opcional '#969696' Color de fondo cuando está activo
backgroundInactiveColor string Opcional '#EDEDED' Color de fondo cuando está inactivo
style ViewStyle Opcional - Estilos personalizados para el contenedor

📏 Tamaños

El componente Switch ofrece 4 tamaños predefinidos:

40x22 px
50x28 px (por defecto)
60x34 px
70x40 px

Estados

Configuración de Tamaños

const sizes = { sm: { width: 40, height: 22, thumbSize: 16, padding: 3, }, md: { width: 50, height: 28, thumbSize: 22, padding: 3, }, lg: { width: 60, height: 34, thumbSize: 28, padding: 3, }, xl: { width: 70, height: 40, thumbSize: 34, padding: 3, }, };

✅ Buenas Prácticas

  • 🏷️ Siempre acompaña el switch con una etiqueta descriptiva
  • 📍 Coloca el switch a la derecha y la etiqueta a la izquierda (convención UX)
  • ⚡ Los cambios deben aplicarse inmediatamente, no requieren botón de guardar
  • 📏 Usa tamaño 'md' para la mayoría de los casos, 'sm' para ajustes secundarios
  • 🎨 Usa colores verdes (#10B981) para indicar "activo" cuando sea apropiado
  • ♿ Asegúrate de que el área táctil sea suficientemente grande (mínimo 44x44)
  • 💬 Provee contexto adicional con texto secundario cuando sea necesario
  • 🔄 Guarda el estado inmediatamente o muestra feedback visual del cambio
  • 📱 Evita poner demasiados switches juntos sin separadores visuales

✨ Animación

El componente Switch usa Animated.spring de React Native para crear transiciones naturales y fluidas. Los parámetros de la animación están optimizados para sentirse responsivos:

Animated.spring(translateX, { toValue: value ? 1 : 0, useNativeDriver: true, bounciness: 8, // Efecto de rebote sutil speed: 12, // Velocidad de la animación }).start();

Características de la Animación

  • ✨ useNativeDriver: La animación se ejecuta en el hilo nativo para mejor rendimiento
  • 🎯 Spring Physics: Movimiento natural con efecto de rebote
  • ⚡ Rápido y Responsivo: Feedback inmediato al tocar
  • 🎨 Transición de Color: El fondo cambia suavemente entre estados

🔧 Notas Técnicas

Dependencias

  • react-native: TouchableOpacity, Animated, View

Rendimiento

El componente usa useNativeDriver: true en las animaciones, lo que significa que la animación se ejecuta completamente en el hilo nativo. Esto garantiza 60 FPS incluso en dispositivos de gama baja.

Funcionamiento Interno

// 1. Valor animado se inicializa según el estado const translateX = useRef(new Animated.Value(value ? 1 : 0)).current; // 2. Se interpola la posición del thumb const thumbTranslateX = translateX.interpolate({ inputRange: [0, 1], outputRange: [0, sizeValues.width - sizeValues.thumbSize - sizeValues.padding * 2], }); // 3. El thumb se anima usando transform transform: [{ translateX: thumbTranslateX }]
⚠️ Nota: No olvides pasar tanto value como onValueChange. El componente es controlado, por lo que necesitas gestionar el estado externamente.

♿ Accesibilidad

Mejora la accesibilidad de tus switches:

<TouchableOpacity accessible={true} accessibilityRole="switch" accessibilityState={{ checked: value }} accessibilityLabel="Activar notificaciones" > <Switch value={value} onValueChange={setValue} /> </TouchableOpacity>

Recomendaciones

  • Usa accessibilityLabel para describir qué hace el switch
  • Incluye accessibilityState con el estado actual
  • Asegúrate de que haya suficiente contraste entre los colores activo/inactivo
  • El área táctil del switch debe ser fácil de presionar (44x44 mínimo)
