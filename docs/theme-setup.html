🎨 Configuración del Tema

Guía completa para configurar Kairox UI Kit en tu aplicación React Native

← Volver a la Documentación

1. Instalación de Dependencias

Kairox UI Kit requiere algunas dependencias adicionales que no vienen por defecto con Expo:

npm install @expo/vector-icons expo-font react-native-keyboard-controller

💡 Nota Importante

Estas dependencias son necesarias para el funcionamiento completo de los componentes. @expo/vector-icons para los iconos, expo-font para las fuentes personalizadas, y react-native-keyboard-controller para el manejo del teclado.

2. Configuración de Fuentes

Kairox UI Kit utiliza la familia tipográfica ComicNeue. Debes cargar estas fuentes en tu aplicación:

Paso 1: Importar las fuentes

En tu archivo App.tsx, importa las fuentes:

import { useFonts } from 'expo-font'; import { bold, boldItalic, italic, light, lightItalic, regular } from './src/theme/Fonts';

Paso 2: Cargar las fuentes

Dentro de tu componente App, carga las fuentes:

export default function App() { const [fontsLoaded] = useFonts({ 'ComicNeue-Bold': bold, 'ComicNeue-BoldItalic': boldItalic, 'ComicNeue-Italic': italic, 'ComicNeue-Light': light, 'ComicNeue-LightItalic': lightItalic, 'ComicNeue-Regular': regular, }); if (!fontsLoaded) { return null; // O un componente de carga } return ( // Tu aplicación aquí ); }

3. Configuración del ThemeProvider

Envuelve tu aplicación con el ThemeProvider para que todos los componentes tengan acceso al tema:

Importar ThemeProvider

import { ThemeProvider } from './src/theme/ThemeProvider';

Envolver la aplicación

export default function App() { const [fontsLoaded] = useFonts({ // ... fuentes configuradas }); if (!fontsLoaded) { return null; } return ( <ThemeProvider> <YourMainComponent /> </ThemeProvider> ); }

4. Uso Básico

Una vez configurado el tema, puedes usar los componentes directamente:

import { Text, Button, Badge } from 'kairox-ui-kit'; export default function MyComponent() { return ( <> <Text variant="lg">Mi texto con tema</Text> <Button variant="solid">Mi botón</Button> <Badge variant="success">Estado</Badge> </> ); }

5. Personalización del Tema

Puedes personalizar el tema pasando un objeto de tema personalizado al ThemeProvider:

const customTheme = { colors: { primary: { 500: '#your-color', }, // ... otros colores personalizados } }; <ThemeProvider customTheme={customTheme}> <YourApp /> </ThemeProvider>
