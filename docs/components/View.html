View Component

Contenedor base con props de estilo extendidas y API simplificada

v1.0.0 React Native

📦 Instalación

Importa el componente desde el UI Kit:

import { View } from './UI';

📖 Descripción

El componente View es un wrapper del componente View nativo de React Native que acepta props de estilo directamente sin necesidad de usar el objeto style. Esto simplifica significativamente el código y hace el desarrollo más rápido.

💡 Tip: Con este componente, puedes pasar props como padding={20} o backgroundColor="white" directamente, en lugar de style={{ padding: 20 }}. Es una mejora significativa en la experiencia de desarrollo!

⚙️ Props

Prop Tipo Requerido Valor por defecto Descripción
children React.ReactNode Opcional - Contenido del View
style ViewStyle Opcional - Objeto de estilos tradicional (sigue funcionando)
...ViewStyle ViewStyle Opcional - Cualquier prop de ViewStyle puede pasarse directamente (padding, margin, flex, backgroundColor, etc.)

Props de estilo disponibles (ejemplos)

Puedes usar cualquier prop válida de ViewStyle de React Native, incluyendo:

  • Layout: flex, flexDirection, justifyContent, alignItems, width, height
  • Spacing: padding, paddingHorizontal, paddingVertical, margin, marginTop, etc.
  • Apariencia: backgroundColor, borderRadius, borderWidth, borderColor
  • Posicionamiento: position, top, bottom, left, right, zIndex
  • Transformaciones: transform, translateX, translateY, scale, rotate
  • Sombras: shadowColor, shadowOffset, shadowOpacity, shadowRadius, elevation

💻 Ejemplos de Uso

Comparación con View nativo
// ❌ Con View nativo de React Native import { View as RNView } from 'react-native'; <RNView style={{ padding: 20, backgroundColor: 'white', borderRadius: 8, }}> <Text>Contenido</Text> </RNView> // ✅ Con View de Kairox UI Kit (más limpio!) import { View } from './UI'; <View padding={20} backgroundColor="white" borderRadius={8} > <Text>Contenido</Text> </View>
Contenedor Flex
<View flex={1} flexDirection="row" justifyContent="space-between" alignItems="center" padding={16} > <Text>Izquierda</Text> <Text>Derecha</Text> </View>
Tarjeta con sombra
<View backgroundColor="white" padding={20} borderRadius={12} shadowColor="#000" shadowOffset={{ width: 0, height: 2 }} shadowOpacity={0.1} shadowRadius={8} elevation={3} marginBottom={16} > <Text variant="lg">Título de tarjeta</Text> <Text>Contenido de la tarjeta</Text> </View>
Grid responsive
<View flexDirection="row" flexWrap="wrap" gap={16} padding={16} > <View flex={1} minWidth="45%" backgroundColor="#F3F4F6" padding={12}> <Text>Item 1</Text> </View> <View flex={1} minWidth="45%" backgroundColor="#F3F4F6" padding={12}> <Text>Item 2</Text> </View> </View>
Posicionamiento absoluto
<View position="relative" height={300}> {/* Badge flotante en esquina superior derecha */} <View position="absolute" top={10} right={10} backgroundColor="#EF4444" padding={8} borderRadius={12} zIndex={10} > <Text color="white">Nuevo</Text> </View> {/* Contenido principal */} <Text>Contenido principal</Text> </View>
Combinando con style tradicional
// Puedes mezclar props directas con el objeto style <View padding={20} backgroundColor="white" style={{ // Estilos adicionales o más complejos transform: [ { rotate: '45deg' }, { scale: 1.2 } ] }} > <Text>Contenido transformado</Text> </View>
Layout de pantalla completo
const HomeScreen = () => ( <View flex={1} backgroundColor="#F8F9FA"> {/* Header */} <View padding={16} backgroundColor="white" borderBottomWidth={1} borderBottomColor="#E5E7EB" > <Text variant="2xl">Mi App</Text> </View> {/* Contenido */} <View flex={1} padding={16}> <Text>Contenido principal</Text> </View> {/* Footer */} <View padding={16} backgroundColor="white" borderTopWidth={1} borderTopColor="#E5E7EB" > <Button title="Acción" /> </View> </View> );

✨ Ventajas

  • 🎯 Código más limpio: Menos anidación de objetos style
  • ⚡ Desarrollo más rápido: Escribes menos código
  • 📖 Más legible: Los props son más fáciles de leer que objetos anidados
  • 🔧 Autocompletado: Mejor soporte de IDE/TypeScript
  • 🔄 Compatible: Funciona con el prop style tradicional
  • 💡 Intuitivo: API más cercana a CSS-in-JS

✅ Buenas Prácticas

  • 🎨 Usa props directas para estilos simples y comunes
  • 📝 Usa el prop style para estilos más complejos (como transforms)
  • 🔄 Combina ambos enfoques cuando sea necesario
  • 📏 Mantén consistencia en tu proyecto sobre cuándo usar cada enfoque
  • 💬 Documenta patrones complejos en tu equipo
  • ⚡ No te preocupes por el rendimiento - es el mismo View nativo

🔧 Notas Técnicas

Implementación

El componente simplemente pasa todos los props al View nativo de React Native:

export const View: React.FC<CustomViewProps> = ({ children, style, ...rest }) => { return ( <RNView style={[ style, {...rest} ]} > {children} </RNView> ); };

TypeScript

El componente extiende ViewStyle, lo que significa que obtiene autocompletado completo para todas las propiedades de estilo de View.

Rendimiento

No hay diferencia de rendimiento con el View nativo - es exactamente el mismo componente con una API más conveniente.
