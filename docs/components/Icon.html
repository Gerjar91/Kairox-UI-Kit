Icon Component

Wrapper universal para iconos con soporte de colores y tamaños personalizables

v1.0.0 React Native

📦 Instalación

Importa el componente desde el UI Kit:

import { Icon } from './UI';

Dependencias de Iconos

El componente Icon funciona con cualquier librería de iconos de React Native. Las más comunes son:

# Expo Vector Icons (recomendado para Expo) npx expo install @expo/vector-icons # React Native Vector Icons npm install react-native-vector-icons

📖 Descripción

El componente Icon es un wrapper universal que te permite usar cualquier icono de cualquier librería (MaterialCommunityIcons, Ionicons, FontAwesome, etc.) con una API consistente y personalizable. Simplifica el manejo de colores, tamaños y estilos.

💡 Tip: Este componente usa la técnica de cloneElement de React para modificar las props del icono que le pases, permitiendo personalización sin importar la librería de iconos que uses.

⚙️ Props

Prop Tipo Requerido Valor por defecto Descripción
as ReactElement Requerido - El componente de icono a renderizar (ej: <MaterialCommunityIcons name="heart" />)
color string Opcional '#5E5E5E' Color del icono
size number Opcional 24 Tamaño del icono en píxeles
style ViewStyle Opcional - Estilos personalizados para el contenedor del icono
...ViewStyle ViewStyle Opcional - Props de estilo como margin, padding, etc.

💻 Ejemplos de Uso

Ejemplo básico con MaterialCommunityIcons
import { Icon } from './UI'; import { MaterialCommunityIcons } from '@expo/vector-icons'; <Icon as={<MaterialCommunityIcons name="heart" />} />
Con color y tamaño personalizados
<Icon as={<MaterialCommunityIcons name="star" />} color="#FFD700" size={32} />
Con diferentes librerías de iconos
import { MaterialCommunityIcons, Ionicons, FontAwesome } from '@expo/vector-icons'; // MaterialCommunityIcons <Icon as={<MaterialCommunityIcons name="home" />} color="#33729E" /> // Ionicons <Icon as={<Ionicons name="settings-outline" />} color="#33729E" /> // FontAwesome <Icon as={<FontAwesome name="user" />} color="#33729E" />
Con estilos de contenedor
<Icon as={<MaterialCommunityIcons name="bell" />} color="white" size={24} style={{ backgroundColor: '#33729E', padding: 12, borderRadius: 25, }} />
Con props de ViewStyle directas
<Icon as={<MaterialCommunityIcons name="account" />} color="#33729E" marginRight={10} backgroundColor="#f0f0f0" padding={8} borderRadius={8} />
En un botón
import { Icon, Button } from './UI'; <Button title="Agregar" leftIcon={ <Icon as={<MaterialCommunityIcons name="plus" />} color="white" size={20} /> } onPress={handleAdd} />
Iconos con badge
import { View, Icon, Badge } from './UI'; <View style={{ position: 'relative' }}> <Icon as={<MaterialCommunityIcons name="bell" />} color="#33729E" size={28} /> <Badge variant="error" size="sm" rounded style={{ position: 'absolute', top: -5, right: -5, }} > 5 </Badge> </View>
Barra de navegación con iconos
const NavigationBar = () => { const navItems = [ { name: 'home', icon: 'home', label: 'Inicio' }, { name: 'search', icon: 'magnify', label: 'Buscar' }, { name: 'profile', icon: 'account', label: 'Perfil' }, ]; return ( <View style={{ flexDirection: 'row', justifyContent: 'space-around' }}> {navItems.map((item) => ( <View key={item.name} style={{ alignItems: 'center' }}> <Icon as={<MaterialCommunityIcons name={item.icon} />} color="#33729E" size={24} /> <Text variant="xs">{item.label}</Text> </View> ))} </View> ); };
Iconos circulares de acción
const ActionButton = ({ icon, onPress, color = '#33729E' }) => ( <TouchableOpacity onPress={onPress}> <Icon as={<MaterialCommunityIcons name={icon} />} color="white" size={24} style={{ backgroundColor: color, padding: 16, borderRadius: 30, }} /> </TouchableOpacity> ); // Uso <ActionButton icon="camera" color="#10B981" onPress={openCamera} />

✅ Buenas Prácticas

  • 🎨 Mantén una paleta de colores consistente para iconos en toda la app
  • 📏 Usa tamaños consistentes: 16-20px para iconos pequeños, 24px para normales, 32px+ para destacados
  • ♿ Asegúrate de que los iconos tengan suficiente contraste con el fondo
  • 🎯 Usa iconos universalmente reconocidos (ej: 🗑️ para eliminar, ⚙️ para configuración)
  • 💡 Combina iconos con texto cuando sea posible para mayor claridad
  • 📱 Mantén un área táctil mínima de 44x44 puntos para iconos clickeables
  • 🔄 Usa una sola librería de iconos en tu proyecto para mantener consistencia visual
  • ⚡ Evita usar iconos demasiado complejos que no se vean bien en tamaños pequeños

🎨 Personalización Avanzada

Iconos con gradiente (usando react-native-linear-gradient)

import LinearGradient from 'react-native-linear-gradient'; import MaskedView from '@react-native-masked-view/masked-view'; const GradientIcon = ({ icon, size = 32 }) => ( <MaskedView maskElement={ <Icon as={<MaterialCommunityIcons name={icon} />} size={size} color="black" /> } > <LinearGradient colors={['#33729E', '#33729E']} style={{ width: size, height: size }} /> </MaskedView> );

Iconos animados

import { Animated } from 'react-native'; const AnimatedIcon = () => { const rotation = useRef(new Animated.Value(0)).current; useEffect(() => { Animated.loop( Animated.timing(rotation, { toValue: 1, duration: 2000, useNativeDriver: true, }) ).start(); }, []); const rotate = rotation.interpolate({ inputRange: [0, 1], outputRange: ['0deg', '360deg'], }); return ( <Animated.View style={{ transform: [{ rotate }] }}> <Icon as={<MaterialCommunityIcons name="loading" />} color="#33729E" size={32} /> </Animated.View> ); };

🔧 Notas Técnicas

Cómo Funciona

El componente usa cloneElement de React para clonar el icono que le pasas y sobrescribir sus props de color y size. Esto permite que funcione con cualquier librería de iconos sin necesidad de crear wrappers específicos.

const iconElement = cloneElement(as, { color: color || iconProps.color, size: size || iconProps.size || 24, });

Orden de Prioridad

  1. Props pasadas al componente Icon (color, size)
  2. Props originales del icono pasado en "as"
  3. Valores por defecto (color: '#5E5E5E', size: 24)
⚠️ Importante: El componente espera que el icono pasado en la prop "as" acepte las props color y size. La mayoría de las librerías de iconos populares siguen esta convención.
