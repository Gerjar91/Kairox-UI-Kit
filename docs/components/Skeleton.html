Skeleton Component

Placeholders animados para estados de carga con shimmer effect

v1.0.0 React Native Animated

📦 Instalación

Importa el componente desde el UI Kit:

import { Skeleton } from './UI';

📖 Descripción

El componente Skeleton proporciona placeholders animados que se muestran mientras se carga el contenido real. Usa un efecto shimmer suave para indicar que el contenido está cargando, mejorando significativamente la percepción de velocidad de tu aplicación.

💡 Tip: Los skeletons mejoran la UX al mostrar la estructura del contenido antes de que esté listo, reduciendo la percepción de tiempo de carga y evitando "layout shifts" bruscos.

⚙️ Props

Prop Tipo Requerido Valor por defecto Descripción
width DimensionValue Opcional '100%' Ancho del skeleton (número o porcentaje)
height DimensionValue Opcional 20 Alto del skeleton en píxeles
borderRadius number Opcional 4 Radio de los bordes redondeados
duration number Opcional 1000 Duración de la animación en milisegundos
baseColor string Opcional '#E1E9EE' Color base del skeleton
highlightColor string Opcional '#F2F8FC' Color del efecto shimmer (highlight)
style ViewStyle Opcional - Estilos personalizados adicionales
...ViewStyle ViewStyle Opcional - Props de estilo como margin, padding, etc.

✅ Buenas Prácticas

  • 📐 Usa dimensiones similares al contenido real para evitar "layout shifts"
  • 🎨 Mantén colores sutiles y no muy contrastantes
  • ⏱️ Muestra skeletons solo cuando la carga tome más de 300-500ms
  • 📱 Crea componentes de skeleton reutilizables para cada tipo de contenido
  • 🔄 No uses skeletons para operaciones instantáneas
  • 📊 Muestra la cantidad correcta de items skeleton (no más de lo necesario)
  • ✨ Usa animaciones sutiles (1000ms es un buen valor)
  • 🎯 Replica la estructura del contenido real lo más fielmente posible

✨ Animación Shimmer

El componente usa Animated de React Native para crear un efecto shimmer que pulsa suavemente, indicando que el contenido está cargando.

const shimmerAnimation = Animated.loop( Animated.sequence([ Animated.timing(animatedValue, { toValue: 1, duration: duration / 2, useNativeDriver: true, }), Animated.timing(animatedValue, { toValue: 0, duration: duration / 2, useNativeDriver: true, }), ]) ); const opacity = animatedValue.interpolate({ inputRange: [0, 1], outputRange: [0.3, 1], });

Características

  • 🔄 Loop infinito: La animación se repite continuamente
  • ⚡ useNativeDriver: Rendimiento optimizado en el hilo nativo
  • 🎭 Interpolación de opacidad: Transición suave entre 0.3 y 1
  • ⏱️ Duración personalizable: Por defecto 1000ms (1 segundo)

🎨 Patrones Comunes

1. Componente Wrapper Reutilizable

const WithSkeleton = ({ isLoading, skeleton, children }) => { if (isLoading) { return skeleton; } return children; }; // Uso <WithSkeleton isLoading={isLoading} skeleton={<ProfileCardSkeleton />} > <ProfileCard data={userData} /> </WithSkeleton>

2. Array de Skeletons

const SkeletonList = ({ count = 3 }) => ( <> {Array.from({ length: count }).map((_, index) => ( <Skeleton key={index} height={60} marginBottom={12} /> ))} </> );

3. Skeleton con Props Dinámicas

const TextSkeleton = ({ lines = 3, lastLineWidth = '80%' }) => ( <> {Array.from({ length: lines }).map((_, index) => ( <Skeleton key={index} width={index === lines - 1 ? lastLineWidth : '100%'} height={16} marginBottom={8} /> ))} </> );

🔧 Notas Técnicas

Dependencias

  • react-native: View, Animated

Rendimiento

La animación usa useNativeDriver: true, lo que garantiza 60 FPS al ejecutarse en el hilo nativo. Esto es crucial cuando tienes múltiples skeletons en pantalla.

Limpieza de Animación

El componente limpia automáticamente la animación cuando se desmonta:

useEffect(() => { shimmerAnimation.start(); return () => { shimmerAnimation.stop(); // Importante para evitar memory leaks }; }, []);
